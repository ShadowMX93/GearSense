# GearSense Wiki

GearSense automatically chooses the right tool for a block, keeps that tool
selected until it breaks, and then moves a matching replacement into the same
hotbar slot. It can also refill used stacks and equip replacement armor when a
worn piece breaks.

## Compatibility

- Paper, Purpur, and Spigot
- Minecraft 1.18.x through Paper 26.2
- Java 17 bytecode; use the Java runtime required by your server version
- One GearSense JAR across the supported server range
